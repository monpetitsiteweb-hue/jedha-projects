AT&T Spam Detector¶

Jedha, Deep Learning project. Goal: flag each SMS as spam or ham (a normal message), from its text only.

Plan:

  1. Data: loading, cleaning, duplicates, EDA
  2. Preprocessing: split into train, validation and test; words turned into numbers
  3. A reference model, not deep learning: TF-IDF + logistic regression
  4. Deep learning models
    • Model 1: word vectors learned from scratch, averaged ("start simple")
    • Model 2: word vectors + Bidirectional LSTM, which reads the words in order
    • Model 3: transfer learning, light: word vectors already trained on a large web corpus (spaCy en_core_web_md), frozen, + Bidirectional GRU
    • Model 4: transfer learning, full: DistilBERT, a whole pre-trained language model, fine-tuned on our SMS
  5. Model choice on the validation set, then one final evaluation on the test set

The settings of the models (layer sizes, learning rate, batch size) are usual values. They were not tuned.

def clean(text):
    t = text.lower()
    t = re.sub(r'http\S+|www\.\S+', ' url ', t)
    t = t.replace('£', ' pound ').replace('$', ' dollar ').replace('&amp;', ' and ').replace('&lt;', ' ').replace('&gt;', ' ')
    t = re.sub(r'\d+', ' num ', t)
    t = re.sub(r"[^a-z' ]", ' ', t)
    return re.sub(r'\s+', ' ', t).strip()

3. Reference baseline (not deep learning): TF-IDF + logistic regression¶

A simple classical model, to judge whether the deep models bring something. TF-IDF gives each word, and each pair of words, a weight: high when the word is frequent in a message and rare elsewhere. A logistic regression then learns one weight per term. ngram_range, min_df and C are usual settings, not tuned. This model is a reference only: it cannot be selected, because the brief asks for a deep learning model. No output here: the scores are in section 5.

4. Deep learning models¶

Defines the common training setup, so that the models are compared under the same rules: Adam, binary cross-entropy, class weights. Early stopping stops the training when the validation loss stops improving, and keeps the best weights: this limits overfitting. Learning rate, batch size and patience are usual settings, not tuned. Patience is the one difference: 5 for Model 1, 3 for Models 2 and 3. No output: the functions are only defined here.

In [13]:
METRICS = [keras.metrics.BinaryAccuracy(name='accuracy'), keras.metrics.Precision(name='precision'),
           keras.metrics.Recall(name='recall'), keras.metrics.AUC(name='auc')]

def train(model, epochs=40, lr=1e-3, batch_size=32, x_tr=None, x_va=None, patience=3):
    x_tr = S_train if x_tr is None else x_tr
    x_va = S_val if x_va is None else x_va
    model.compile(optimizer=keras.optimizers.Adam(lr), loss='binary_crossentropy', metrics=METRICS)
    es = keras.callbacks.EarlyStopping(monitor='val_loss', patience=patience, restore_best_weights=True)
    hist = model.fit(x_tr, y_train, validation_data=(x_va, y_val), epochs=epochs, batch_size=batch_size,
                     class_weight=class_weight, callbacks=[es], verbose=0)
    print(f'{model.name}: stopped after {len(hist.history["loss"])} epochs, best val_loss={min(hist.history["val_loss"]):.4f}')
    return hist

def plot_history(hist, title):
    h = pd.DataFrame(hist.history)
    fig, ax = plt.subplots(1, 3, figsize=(15, 3.5))
    for a, m in zip(ax, ['loss', 'recall', 'precision']):
        a.plot(h[m], label='train'); a.plot(h['val_' + m], label='validation'); a.set_title(f'{title}: {m}'); a.set_xlabel('epoch'); a.legend()
    plt.tight_layout(); plt.show()

Model 1: Embedding + Global Average Pooling (start simple)¶

The brief says to start simple. Each word gets a vector of 32 values, learned during training. The message is the average of its word vectors, padding positions included (no mask, see the code comment), and a small dense layer decides. This model ignores word order. Layer sizes are usual settings, not tuned. The output shows 320,545 parameters. Training stopped after 30 epochs, with a best validation loss of 0.0460.

Model 3: Transfer learning with pre-trained word vectors¶

We have only 3,567 training messages, and the brief suggests transfer learning. Instead of learning word vectors from scratch, this cell loads the 300-value vectors of spaCy en_core_web_md, trained on a large web corpus. The output shows vectors for 5,512 of the 6,374 words of the vocabulary (86%).

In [16]:
import spacy
nlp_vec = spacy.load('en_core_web_md', exclude=['tagger', 'parser', 'ner', 'lemmatizer', 'attribute_ruler', 'senter'])
EMB_DIM = nlp_vec.vocab.vectors_length
emb_matrix = np.zeros((len(vocab), EMB_DIM), dtype='float32')
hits = 0
for i, w in enumerate(vocab):
    if i < 2: continue  # padding and OOV tokens
    if nlp_vec.vocab.has_vector(w):
        emb_matrix[i] = nlp_vec.vocab.get_vector(w); hits += 1
print(f'Pre-trained vectors found for {hits}/{len(vocab) - 2} words ({hits / (len(vocab) - 2):.0%})')

Model 4: fine-tuning DistilBERT¶

The second kind of transfer. Not only pre-trained word vectors this time, but a whole pre-trained language model: DistilBERT, 66 million parameters, trained on a large English corpus and shared by Hugging Face. We keep its body, add a small head that decides spam or ham, and train the whole thing on our SMS for 2 passes, with a small learning rate and the same class weights. The raw text is used, not the cleaned one: the DistilBERT tokenizer handles casing, digits and punctuation itself. RUN_DISTILBERT = False would skip this cell.

The output shows the download of the model, a load report (the MISSING lines are the new head, trained here), then the training loss: 0.1465 after the first pass, 0.0401 after the second.

5. Evaluation¶

Comparison on the validation set¶

The default threshold is 0.5: above it, the model says spam. Because spam is rare, this cell picks, for each model, the threshold that gives the best F1 on the validation set, then gives its scores on that same set. F1 combines precision and recall on the spam class. These scores are a little optimistic, because the threshold is chosen on the same data, but it is the same for all models. The test set is not used here.

The output shows, on 89 spams: DistilBERT 96.09%, pre-trained vectors + BiGRU 95.40%, simple model 94.12%, TF-IDF baseline 92.86%, BiLSTM 92.49%. The thresholds go from 0.35 to 0.91.

def best_threshold(y, p):
    grid = np.linspace(0.05, 0.95, 91)
    return grid[np.argmax([f1_score(y, p >= t) for t in grid])]

def scores(y, p, t):
    pred = (p >= t).astype(int)
    return {'accuracy': accuracy_score(y, pred), 'precision': precision_score(y, pred), 'recall': recall_score(y, pred),
            'f1': f1_score(y, pred), 'roc_auc': roc_auc_score(y, p), 'threshold': t}

Achieved performance: the selected deep learning model (DistilBERT, fine-tuned) detects 95.6% of spams (86 of 90) with 95.6% precision (4 legitimate SMS wrongly flagged out of 675). F1 score 95.6%, accuracy 98.9%, ROC AUC 0.995.

How to read these results:

  • The two transfer models come first. The more the model reuses what was learned elsewhere, the better it does on 3,567 training messages: a whole pre-trained model (M4) beats pre-trained word vectors (M3), which beat the networks trained from scratch (M1, M2).
  • On validation, F1 goes from 92.5% to 96.1%. With 89 spams, one spam is worth more than 1 point of recall, so the gaps between models are a few messages.
  • The TF-IDF baseline stays in the range of the small networks, with a much simpler model.
  • F1 goes from 96.1% on validation to 95.6% on test: the score holds on messages never used for a decision.
  • The cost: DistilBERT has 66 million parameters, against 64,000 trained for M3. It needs PyTorch and more compute. M3 is the light fallback, and the model saved by this notebook.
  • The settings of the models are usual values, not tuned. DistilBERT was trained for 2 passes only.

Next steps: cross-validation for more stable scores, a few more passes for DistilBERT with a stop on the validation loss, and monitoring on recent SMS, because spam wording changes over time.
