# The North Face e-commerce (Jedha, Bloc 3)

Text clustering, a product recommender and topic modeling on 500 product descriptions.

- Notebook: `the_north_face_project/the_north_face_ecommerce.ipynb`, with its outputs, and its HTML export.
- Command-line recommender: `the_north_face_project/recommender.py`.
- Summary, in French: `SYNTHESE.md`.

## Data

The data file is `data/sample-data.csv`.
