# Jedha projects

Projects of the Jedha Data Science Fullstack training, for the CDSD certification. Each folder has its own README, including where to download any data that is not in this repository.

| Project | Certification block | Subject | Folder |
|---|---|---|---|
| Kayak | Block 1 | Collect weather and hotel data for French cities, store it in a data lake and a SQL warehouse, and map the best destinations and hotels. | [01_kayak](01_kayak) |
| Steam | Block 2 | Analyze the Steam video game catalogue with PySpark on Databricks for Ubisoft. | [02_steam](02_steam) |
| Speed Dating | Block 2 | Explore which attributes go with the decision to see a speed dating partner again. | [03_speed_dating](03_speed_dating) |
| Walmart | Block 3 | Predict weekly store sales with linear and regularized regression. | [04_walmart](04_walmart) |
| Conversion rate | Block 3 | Predict newsletter subscriptions and optimize the f1-score. | [05_conversion_rate](05_conversion_rate) |
| Uber | Block 3 | Find hot zones in New York City by day of week and hour with unsupervised clustering. | [06_uber](06_uber) |
| The North Face | Block 3 | Cluster product descriptions, recommend similar products and extract topics. | [07_north_face](07_north_face) |
| AT&T | Block 4 | Detect spam SMS with deep learning. | [08_att_spam](08_att_spam) |
| Getaround | Block 5 | Analyze late checkouts and deploy a pricing API and a dashboard. [Dashboard](https://mpsw-getaround-dashboard.hf.space), [API](https://mpsw-getaround-api.hf.space/docs). | [09_getaround](09_getaround) |

The five projects presented at the oral exam (blocks 1 to 5) also contain the presentation slides: open the `*-slides.html` file of the folder in a browser.
